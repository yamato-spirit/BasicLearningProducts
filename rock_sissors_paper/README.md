# Simple Janken Game (Console App)

Javaで作成したコンソール対話型のじゃんけんゲームです。
オブジェクト指向設計に基づき、各クラスの責務（入力・判定・CPU・表示）を明確に分離しています。

## 📦 機能・特徴

- **対話型インターフェース**: コンソール上でユーザーが手を入力して遊びます。
- **入力バリデーション**: 正規表現を用い、`1`〜`3` 以外の不正な入力を堅牢に排除します。
- **判定ロジック**: `(user - com + 3) % 3` の演算アルゴリズムによる、拡張性の高い判定を行っています。
- **あいこループ**: 勝負がつくまで自動的にゲームが続行されます。

## 🛠 技術的こだわり（設計）

本アプリケーションでは、**依存性の注入（Dependency Injection）** パターンを採用しています。
`Scanner` や `Random` といったリソースを管理するインスタンスを `Main` クラスで一元管理し、各クラス（`User`, `Com`）のコンストラクタ経由で渡しています。

これにより、以下のメリットを実現しています。
- **メモリ効率の向上**: 無駄なインスタンス生成（`new`）を抑制。
- **乱数の品質確保**: `Random` インスタンスを再利用することで、シード値の重複による乱数の偏りを防止。
- **テスタビリティ**: 将来的にテストコードを書く際、モック（偽物の入力や乱数）に差し替えやすい設計。
